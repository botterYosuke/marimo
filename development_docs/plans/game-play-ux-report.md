# ゲームプレイ UX レポート — 離脱ポイント分析

**日時**: 2026-02-20
**対象**: `src-tauri/sample-notebooks/backcast.py`（サンドボックスモード）
**環境**: marimo edit (port 2718) + Vite dev server (port 3000)
**参考**: `development_docs/game-e2e-review-system.md`

---

## 実施内容

1. `backcast.py` をmarimo editで起動
2. チャート表示（`bt.chart("7203")`）を確認
3. `bt.buy()` を入力・実行
4. `bt.step()` を入力・実行
5. スキルツリーダイアログを開いて進捗確認
6. 各段階でスクリーンショット取得・UI検証

---

## 離脱ポイント一覧（深刻度順）

### 1. 🔴 スキル完了のフィードバックが無い / 進捗ゼロのまま

**深刻度: 致命的**

`bt.buy()` と `bt.step()` を実行した後にスキルツリーを開いたところ、**0/59 スキル**のまま。SANDBOX_001（マーケットへようこそ）すら完了扱いになっていない。

**原因推定**:
- 既存セッションへの再接続（Reconnected）により、`bt.chart("7203")` の emit_skill("SANDBOX_001") が発火したタイミングではフロントエンドのスキルツリーリスナーが未接続だった
- BroadcastChannel メッセージはリアルタイムのみ送信で、過去の発火は受け取れない

**離脱理由**: 「買ったのに何も起きない」「ゲームが壊れている」と感じて閉じる

**改善案**:
- ページロード時にカーネルから現在の `get_triggered_skills()` 状態を取得し、フロントエンドと同期する仕組み
- または、セル出力再送時にスキルイベントを再発火する

---

### 2. 🔴 `bt.buy()` の出力が意味不明

**深刻度: 高**

`bt.buy()` を実行すると、Outputs パネルに以下が表示される:

```
<BackcastPro.order.Order object at 0x000001D007657CB0>
```

初心者にはこのPythonオブジェクトの repr() は完全に意味不明。「買えたの？ 買えなかったの？ エラー？」と混乱する。

**離脱理由**: 「何が起きたかわからない」「エラーっぽい文字列が出た」

**改善案**:
- `Order.__repr__()` を人間に読みやすい形式にする: `"✅ 買い注文: トヨタ(7203) 1株 @ ¥3,138"`
- `game_setup.py` の `buy()` 関数で `mo.output.append()` でフレンドリーなメッセージを表示

---

### 3. 🔴 `bt.step()` の出力が `True` のみ

**深刻度: 高**

`bt.step()` を実行すると Outputs に `True` とだけ表示される。

- 「何日に進んだの？」
- 「株価は上がった？ 下がった？」
- 「買い注文は約定した？」

何の情報もなく、ユーザーは次に何をすべきかわからない。

**離脱理由**: 「True って何？」「ゲームが進んでるのかわからない」

**改善案**:
- `step()` の戻り値を `f"📅 {date} に進みました | 株価: ¥{price:,.0f} | 含み損益: ¥{pl:+,.0f}"` のような形式に
- ステータスバーの更新と連動した視覚フィードバック

---

### 4. 🟠 Grid レイアウトのセル重なり

**深刻度: 中**

ゲーム起動直後、4つのセルが grid レイアウト上で重なり合っている:

- cell-1（説明マークダウン）がチャートの上に被さる
- cell-2（`bt.chart("7203")`）とcell-3（入力セル）が画面下部で重なる
- cell-4（AI自動生成の空セル）が中央に浮いている

**離脱理由**: 「画面がぐちゃぐちゃで何がどこかわからない」

**改善案**:
- grid レイアウトの初期配置を改善（セルが重ならないように）
- チャートを上半分、説明+入力を下半分に明確に分離

---

### 5. 🟠 AI Fix 提案が全セルに表示される

**深刻度: 中**

全てのコードセルに「Fix generated」「Showing fix」「Accept / Reject」バナーが表示されている。これはゲームとは無関係のAIコード修正提案で、ゲーム初心者を大いに混乱させる。

**離脱理由**: 「Accept? Reject? 何を承認するの？」「ゲームの一部？」

**改善案**:
- ゲームモード（backcast テンプレート）では AI Fix を自動非表示にする
- または `app.setup` や metadata でフラグ設定

---

### 6. 🟠 「どこにコードを入力するか」がわからない

**深刻度: 中**

説明には「黒いウィンドウに `bt.buy()` と入力して実行」と書いてあるが:

- cell-3（意図された入力セル）は画面下端で小さく表示
- cell-4（AI が生成した空セル）も「黒いウィンドウ」に見える
- 複数のテキストボックスがあり、どれが「正しい入力場所」か判断できない

**離脱理由**: 「どこに書けばいいの？」

**改善案**:
- 入力セルを目立たせる（ハイライト、矢印アイコン、プレースホルダーテキスト改善）
- 「ここに入力 →」のような視覚的ガイド
- 不要なセル（cell-4）の自動生成を抑制

---

### 7. 🟡 チャートが step() 後に意味不明な表示になる

**深刻度: 低〜中**

`bt.step()` 実行後、TradingView チャートが大きく変化する:
- ローソク足が 1 本しかない極端にズームされた表示
- チャートの大部分が空白
- 「BUY」マーカーは表示されるが、それだけ

**離脱理由**: 「チャートが壊れた？」

**改善案**:
- step() 後のチャート再描画時に適切なズームレベルを維持
- 直近N日分のローソク足が見える範囲にフィット

---

### 8. 🟡 「Reconnected」バナーが意味不明

**深刻度: 低〜中**

開発サーバー経由で接続すると「Reconnected: You have reconnected to an existing session.」バナーが表示される。ゲームプレイヤーにとっては意味不明。

**離脱理由**: 「何かエラー？ Restartすべき？」

**改善案**:
- ゲームモードでは自動 dismiss
- またはゲーム向けのメッセージに変更（「前回の続きから再開しました」等）

---

### 9. 🟡 ステータスバーが Progress: 0.0% のまま

**深刻度: 低**

画面上部のステータスバーに `Progress: 0.0%` が表示されるが、操作しても変わらない。`Time: -` も常にハイフンのまま。

**離脱理由**: 「操作してるのに何も進んでない」

**改善案**:
- `bt.step()` 実行後に Time と Progress を更新
- 視覚的に変化があることを示す（アニメーション等）

---

### 10. 🟡 スキルツリーボタンの存在に気づけない

**深刻度: 低**

スキルツリーは右サイドバーの小さなボタン（`data-testid="skill-tree-button"`）をクリックしないと開かない。ゲームの核心機能であるにも関わらず、発見困難。

**離脱理由**: 「このゲームの目標は何？ 進捗はどう確認する？」

**改善案**:
- 初回プレイ時にスキルツリーを自動表示
- スキル完了時にツリーがポップアップ
- ボタンを目立たせる（パルスアニメーション、バッジ通知）

---

## 総合評価

| 段階 | 離脱リスク | 主な原因 |
|------|-----------|---------|
| 起動直後 | **高** | Grid レイアウト混乱 + AI Fix 表示 |
| `bt.buy()` 実行後 | **致命的** | 出力が `<Order object>` で意味不明 |
| `bt.step()` 実行後 | **高** | 出力が `True` + チャート表示崩れ |
| スキルツリー確認時 | **致命的** | 進捗 0/59 のまま（スキル未発火） |
| 次のアクション判断 | **高** | ガイダンスなし、何をすべきか不明 |

**最も深刻な離脱ポイント**: 「操作したのにスキルが進まない」と「出力が意味不明」の2つ。この2点が改善されれば、ゲームの継続率は大幅に向上すると予測。
