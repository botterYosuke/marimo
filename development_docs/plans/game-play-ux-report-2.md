## 離脱ポイント一覧（深刻度順）

### 1. 🔴 スキル 0/59 のまま（前回から継続）

**深刻度: 致命的**

buy → step × 2 → sell → step の**完全なトレードサイクル**を完了し、利益 ¥3,576 を獲得した後もスキルは **0/59** のまま。スキルツリーを開くと2枚のカード（「マーケットへようこそ」「初めての購入」）が表示されるが、どちらも未完了（◯と🔒）。

**ログ確認**: コンソールには `[SkillHandler] Received skill event: SANDBOX_001/002/004` が飛んでいる（emit 自体は成功）にもかかわらず、UIのカウントは 0/59 のまま。

**原因**: セッション再接続時にスキルリスナーが未接続のまま emit されたイベントが捨てられるため（前回と同じ）。

**離脱理由**: 「散々操作したのに0/59って何？ ゲームが壊れてる」→ 閉じる

---

### 2. 🔴 右パネルの指示が一切更新されない

**深刻度: 致命的（新規）**

cell-1 のマークダウン（「今すぐできること」）は、ゲームの進行状態に関係なく**常に同じ4ステップを表示し続ける**：

```
1. 時間を進める: bt.step() で次の日に進む
2. 株を買う注文する: 黒いウィンドウに bt.buy() と入力して実行
3. 買注文が決済される: bt.step() で次の日に進むと注文が決済されました！
4. チャートを見る: bt.step() で日を進めて株価の動きを確認

最初の目標
「株を買う！！」
```

完全サイクルが終わっても「最初の目標：株を買う！！」のまま。ユーザーには「次に何をすべきか」が全くわからない。

**具体的に困る場面**:
- `bt.buy()` した後 → 指示は「買え」のまま。「もう買ったよ？」
- `bt.step()` 2回した後 → 指示は「stepを実行しろ」のまま。「いつまで続ければいい？」
- `bt.sell()` した後 → 指示は「買え」のまま。完全に文脈がズレている

**離脱理由**: 「何を目指せばいいかわからない」「指示が全部同じで進んでる気がしない」

**改善案**:
- セル出力でリアクティブな指示を出す（`mo.callout` でその時点での次のアクションを示す）
- またはスキル達成ごとに指示テキストが自動更新される仕組み（マーカー変数を使う）

---

### 3. 🔴 Outputs パネルが最新出力のみ表示（履歴なし）

**深刻度: 致命的（新規）**

cell-3 を実行するたびに Outputs パネルは**前回の出力を完全に消して最新出力のみを表示**する。

実際の遷移：
```
bt.buy()  実行 → 「買い注文を出しました — 7203 @ ¥3,138」（緑callout）
bt.step() 実行 → 「2001-01-04 に進みました…」（青callout）← buy callout が消える
bt.sell() 実行 → 「売り注文を出しました — 7203 @ ¥3,810」（緑callout）← step callout が消える
bt.step() 実行 → 「2001-01-09 に進みました…」（青callout）← sell callout が消える
```

ユーザーは「さっきの buy は成功した？」「いくらで売れた？」を確認できない。操作の履歴が完全に消える。

**離脱理由**: 「売れたっていう画面が一瞬で消えた」「買えたか確認したいのにもう見えない」

**改善案**:
- セル出力を累積表示する（marimo は `mo.output.append()` で追記可能）
- または「直前の操作サマリー」を常時表示するウィジェットを追加

---

### 4. 🟠 3D ドローンが画面内を飛び回る

**深刻度: 高（新規）**

画面上に sci-fi 系の 3D ドローンモデルが登場し、チャートエリア・空白エリアを問わず飛び回る。

観察した挙動：
- **起動直後**: チャート中央付近を飛び回る（ローソク足と重なる）
- **step() 実行後**: チャート内の価格データに重なる位置に来ることがある
- **空白エリア**: 意味なく灰色の空白を飛んでいる
- ドローンを避けてチャートを見ようとするも、動き続けるため視線が奪われる

**コンソールログ**: `ローターが見つかりませんでした。モデル構造を確認してください。` → モデルのアニメーション（ローター回転）が意図通り動いていない可能性あり

**離脱理由**:
- 「何これ？ 邪魔」「チャートを見たいのに動くものが気になる」
- ゲームのテーマ（株式投資）とドローンの関連性が不明

**改善案**:
- ドローンをチャートエリア外に固定する（または別のレイヤーに分離）
- ドローン出現に意味（スキル達成時のアニメーション等）を持たせる
- ローターアニメーションの修正

---

### 5. 🟠 sell() 後にステータスバーが古い状態のまま

**深刻度: 高（新規）**

`bt.sell()` を実行した直後：
- ✅ Outputs パネルに「売り注文を出しました」の緑 callout → OK
- ❌ ステータスバーの Position: **27 shares のまま**
- ❌ ステータスバーの Cash: **¥99,900 のまま**

次の `bt.step()` を実行して初めて：
- Position: 0 shares（決済完了）
- Cash: ¥103,576（利益込み）

つまり、`bt.sell()` は「注文予約」だが、ユーザーはそれを理解できない。callout は「売りました」と言っているのに、ステータスは「まだ持っている」と言っている。

**離脱理由**: 「売れたって書いてあるのに株がまだある？ バグ？」「お金が減ったまま戻ってこない」

**改善案**:
- sell() callout に「明日の始値で約定します（次回 step() 後に反映）」の一文を追加
- またはステータスバーに「注文中」のバッジを表示

---

### 6. 🟠 スキルカードの報酬が負の数字で表示される

**深刻度: 高（新規）**

スキルツリーを開くと、各スキルカードの報酬欄が：
- 「マーケットへようこそ」: `-30,000円 -1`
- 「初めての購入」: `-20,000円`

そして左下には `¥0`（所持金ゼロ）が表示されている。

「-30,000円 を払って達成する」という読み方になり、投資ゲームで**損をするためにスキルを達成する**という意味に見える。直感的には報酬は **+30,000円** であるべき。

**離脱理由**: 「スキルをとると損するの？ やる気ゼロ」「これお金かかるの？」

**改善案**:
- 報酬を正の数値で表示（`+30,000円` 形式）
- またはコインアイコンなどで「もらえる報酬」と明確に示す

---

### 7. 🟠 Progress: 0.0% のまま変化しない（前回から継続）

**深刻度: 高**

ステータスバーの Progress がトレード完了後も **0.0% のまま**。Time は `2001-01-09 00:00:00` に更新されているが、Progress だけが反応しない。

完全サイクル（buy→step→sell→step）を終え、¥103,576（+3.6%利益）を達成したにもかかわらず Progress は 0.0% を指し続ける。

**改善案**:
- step() のたびに「現在日付 / 総日数」を計算して Progress を更新する
- Progress の定義（何の進捗か）をユーザーに明示する

---

### 8. 🟡 Outputs パネルでテキストが途中で折り返される

**深刻度: 中（新規）**

step() 実行後の Outputs パネル（右上の小さいボックス）での表示：

```
2001-01-09 に進みまし
た

株価: ¥3,840 | 資産:
¥103,576
```

「に進みました」が「に進みまし」と「た」に分割される。また「| 資産:」の後で折り返されて数値が次行に来る。

**改善案**:
- Outputs パネルを少し広げる、または折り返し位置を調整する
- callout の文字サイズを調整する

---

### 9. 🟡 チャートが step() 後に数本のローソク足しか表示しない（前回から継続）

**深刻度: 中**

`bt.step()` 実行後、チャートは全期間の履歴ではなく**最近の数本のローソク足**だけを表示する。

観察：
- step() 1回後: 1本（巨大な緑ローソク1本のみ）
- step() 2回後: 2本
- step() 3回後: 3-4本
- buy後の大きい緑ローソクが画面の大部分を占める

起動直後の「全期間チャート」の印象と大きく乖離する。

### 10. 🟡 「Reconnected」バナー + Restart の意味が不明（前回から継続）

**深刻度: 中**

接続時に「You have reconnected to an existing session.」バナーが表示される。「Restart」ボタンの意味（データがリセットされるのか？）が不明。

初心者には「エラーが出た」「リスタートすると最初からになる？」と感じられる。
