# Issue: スキルツリーの報酬表示が「-30,000円」とマイナス表記になり意味が逆に見える

**報告日**: 2026-02-21
**重要度**: P3
**状態**: Open

## 症状

スキルツリーダイアログ内でスキルの報酬が「-30,000円」のようにマイナス記号付きで表示される。実際には報酬（プレイヤーにとってのプラス）のはずであるが、マイナス表記のため「罰則」または「コスト」として誤解される可能性がある。

- SANDBOX_001「マーケットへようこそ」の報酬: `-30,000円 ·1` と表示
- SANDBOX_002「初めての購入」の報酬: `-20,000円` と表示

## 再現手順

1. `backcast.py` をマリモで開く
2. 右下の「スキルツリー」ボタンをクリックする
3. スキルツリーダイアログが表示される
4. SANDBOX_001「マーケットへようこそ」の報酬欄に「-30,000円 ·1」と表示されていることを確認する

## 原因分析

報酬値がバックエンドでマイナス符号付きの数値として定義されているか、フロントエンドの表示ロジックで符号の反転が行われていない可能性がある。

考えられるパターン:

1. **データ定義の問題**: スキルの報酬が `reward: -30000` のように負の値として定義されており、表示時に「報酬としてのプラスの意味」に変換する処理がない
2. **表示ロジックの問題**: 報酬値をそのまま `${reward}円` と表示しており、符号の意味解釈がされていない
3. **ゲームデザインの問題**: 報酬が「プレイヤーが支払うコスト」として設計されており、実際にはスキル習得コストである可能性（この場合は表示文言の問題）

調査対象:
- `src-tauri/sample-notebooks/skill_events.py` のスキル定義における `reward` フィールドの値
- フロントエンドのスキルツリーコンポーネントでの報酬表示ロジック

## 影響範囲

- **ゲームの直感的な理解**: 報酬がマイナスに見えることで、スキル習得を「損」と感じさせる可能性がある
- **新規プレイヤーの混乱**: チュートリアル段階でゲームの仕組みを誤解させるリスク
- **ゲームデザインの意図との乖離**: スキルツリーは「達成による報酬獲得」を表すはずが、コスト表示に見える

## 対応案

### 調査後の対応（表示の問題の場合）

報酬値の絶対値を表示し、プラス記号を付ける:

```tsx
// Before
<span>{reward}円</span>

// After
<span>+{Math.abs(reward).toLocaleString()}円</span>
```

### 調査後の対応（データ定義の問題の場合）

スキル定義ファイル（`skill_events.py`）で報酬を正の値として定義し直す:

```python
# Before
"reward": -30000  # 意図不明な負値

# After
"reward": 30000   # 正の報酬として定義
```

### ゲームデザインの明確化

報酬の表示に「+¥30,000 獲得」のようなポジティブな文言を使用し、プレイヤーにとって直感的な表示にする。
