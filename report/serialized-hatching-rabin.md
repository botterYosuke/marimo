# Grid レイアウト（3Dモード）追加の見落とし修正

## 概要
`main` ブランチ（Electron版）から `sasa/ma` ブランチ（Tauri版）へ移植した Grid レイアウト（3Dモード）で、いくつかの変更が見落とされています。

## 修正が必要なファイル一覧

### 1. `frontend/src/components/editor/renderers/cell-array.tsx`

**見落とし内容:**
- `is3DModeAtom` のインポートが削除されている
- `is3DMode` の `useAtomValue` 使用が削除されている
- `is3DMode ? "pb-4" : "pb-32"` の条件分岐が `pb-32` 固定になっている
- `asChild={true}` が `asChild={false}` に変更されている
- `pointer-events-none` / `pointer-events-auto` のクラスが削除されている

**必要な修正:**
```tsx
// インポート追加
import { is3DModeAtom } from "@/core/mode";

// useAtomValue追加
const is3DMode = useAtomValue(is3DModeAtom);

// クラス名を条件分岐に修正
<div className={cn("flex justify-center mt-4 pt-6 group gap-4 w-full print:hidden pointer-events-none", is3DMode ? "pb-4" : "pb-32")}>
  <div className={cn(
    "shadow-sm border border-border rounded transition-all duration-200 overflow-hidden divide-x divide-border flex pointer-events-auto bg-background",
    ...

// asChildを修正
asChild={true}
```

## 修正優先度

| 優先度 | ファイル | 理由 |
|--------|----------|------|
| 高 | cell-array.tsx | 3Dモード時のUI表示に直接影響 |
| 高 | cells-renderer.tsx | EditGridLayoutRendererの使用に必須 |
| 高 | layout.ts | 3Dポジション管理の中核 |
| 中 | handlers.ts | 自動配置・ポジション復元に必要 |
| 中 | auto-placement.ts | セル自動配置に必要 |
| 中 | visual-output-detector.ts | ビジュアル出力検出に必要 |
| 中 | saving/state.ts | 3Dポジション保存状態管理 |
| 中 | save-component.tsx | 3Dポジション保存 |
| 低 | grid-layout.tsx | SETUP_CELLの除外 |
| 低 | config-schema.ts | デフォルト値（既存ノートブックには影響少） |
| 低 | `__tests__/auto-placement.test.ts` | テストファイル |

## 検証手順

1. `pnpm build` でビルドエラーがないことを確認
2. `pnpm typecheck` で型エラーがないことを確認

4. セルのドラッグ移動が動作することを確認
5. ページリロード後にセル位置が復元されることを確認
