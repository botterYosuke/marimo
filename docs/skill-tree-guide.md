# スキルツリー＆Backcastゲームガイド

## 🎮 スキルツリーシステムとは？

marimoに統合されたゲーミフィケーション機能で、コーディングスキルを楽しく習得できるシステムです。
Pythonコードを実行してタスクを達成すると、**スキル**が解禁され、報酬を獲得できます。

### 主な特徴

- 📊 **進捗の可視化**: スキルグラフで自分の成長を一目で確認
- 🎁 **報酬システム**: スキル達成で現金、称号、新機能を獲得
- 🎯 **段階的学習**: 3つのモード（Sandbox → Bridge → Full）で無理なくステップアップ
- 🔗 **前提条件**: スキルツリー形式で、基礎から応用へ自然に進める

---

## 🗺️ スキルツリーの開き方

### エディタツールバーから開く

1. marimoエディタを開く
2. ツールバーの **🎮 スキルツリーアイコン** をクリック
3. ダイアログでスキルグラフが表示されます

### サイドパネルから開く

- エディタ右側のサイドパネルに「Skill Tree」タブがあります
- トラック切り替え（All / Sandbox / Bridge / Full）が可能

---

## 📚 3つのゲームモード

### 🏖️ Sandbox（サンドボックス）モード

**初心者向けの安全な学習環境**

- **目的**: 基本操作を学ぶ
- **スキル数**: 6個（SANDBOX_001 〜 SANDBOX_006）
- **内容**: 株の購入・売却、データ確認など基礎的な操作
- **卒業条件**: SANDBOX_001〜005を全て完了すると、自動的にSANDBOX_006が発火

### 🌉 Bridge（ブリッジ）モード

**システムの内部仕組みを理解するステージ**

- **目的**: データの正体を知り、仕組みを理解する
- **スキル数**: 3個以上（BRIDGE_001 〜 BRIDGE_003）
- **内容**: データソースの確認、APIの使い方
- **卒業条件**: BRIDGE_002完了で自動的にBRIDGE_003が発火

### 🚀 Full（フル）モード

**完全な機能を使用できるステージ**

- すべての機能が解禁
- 高度なトレード戦略、インジケーター、リスク管理が可能

## 🎮 Backcast投資ゲームの遊び方

**Backcast**は、株式投資のバックテストを体験できるシミュレーションゲームです。
トヨタ自動車（7203）の実際の株価データを使って、投資の基礎を学べます。

### 🚀 クイックスタート

#### 1. ゲームファイルを開く

```bash
# marimoでBackcastゲームを開く
marimo edit ~/notebooks/backcast.py
```

#### 2. 最初のミッション：「株を買う！」

画面の指示に従って、黒いコードセルに以下を入力：

```python
bt.buy()
```

`Shift + Enter` で実行 → **SANDBOX_002スキル獲得！** 🎉

#### 3. 時間を進める

```python
bt.step()
```

翌日に進みます。株価の変動を確認しましょう。

#### 4. 保有株を確認

```python
bt.trades()
```

**SANDBOX_003スキル獲得！**

#### 5. 株を売却

```python
bt.sell()
```

**SANDBOX_004スキル獲得！**

## 📖 Backcast API リファレンス

### 基本操作

| 関数 | 説明 | 獲得スキル |
|------|------|----------|
| `bt.chart(code)` | 銘柄のチャートを表示 | SANDBOX_001 |
| `bt.buy()` | 株を購入 | SANDBOX_002 |
| `bt.sell()` | 株を売却 | SANDBOX_004 |
| `bt.step()` | 次の日に進む | - |
| `bt.trades()` | 保有中の取引を確認 | SANDBOX_003 |

### データ分析（ブリッジモード）

| 関数 | 説明 | 獲得スキル |
|------|------|----------|
| `bt.reveal_data()` | 使用中のデータの詳細を表示 | BRIDGE_001 |
| `bt.get_stock_daily(code)` | 銘柄の株価データを取得 | BRIDGE_002 |

## 🎯 サンドボックス完全攻略

### ステップバイステップガイド

```python
# ステップ1: チャート表示

# → SANDBOX_001 獲得 ✅

# ステップ2: 株を購入
bt.buy()
# → SANDBOX_002 獲得 ✅

# ステップ3: 時間を進める
bt.step()

# ステップ4: 保有株確認
bt.trades()
# → SANDBOX_003 獲得 ✅

# ステップ5: 株を売却
bt.sell()
# → SANDBOX_004 獲得 ✅

# ステップ6: チャート再表示（2回目）

# → SANDBOX_005 獲得 ✅（003と004が完了している場合）

# 🎊 自動的にSANDBOX_006が発火！サンドボックス完全クリア！
```

## 🏆 進捗の確認方法

### スキルツリーダイアログ

- **完了スキル数**: 「X/59 スキル」形式で表示
- **獲得現金**: 累計報酬額を表示
- **スキルノードの色**:
  - 🟢 **緑色**: 完了済み
  - 🔵 **青色**: 解禁済み（プレイ可能）
  - ⚫ **グレー**: ロック中（前提条件未達成）

### 報酬トースト通知

スキル達成時に画面右下にトースト通知が表示されます：

```
🎉 SANDBOX_001 達成！
💰 ¥1,000 獲得
```

## 💡 ヒント＆Tips

### 🎯 効率的なスキル獲得

1. **順番に進める**: スキルには前提条件があります。基礎から順に学びましょう
2. **失敗を恐れない**: FAIL系スキルも立派な達成です
3. **ヘルプセルを活用**: スキルクリック時に自動挿入されるヘルプセルを読みましょう

### 🔧 トラブルシューティング

**Q: スキルが発火しない**

A: 以下を確認してください：
- 前提条件のスキルを完了しているか
- コードを正しく実行しているか（`Shift + Enter`）
- marimoサーバーが起動しているか

**Q: 進捗がリセットされた**

A: スキル進捗は現在セッション内でのみ保存されます。永続化は今後のアップデートで対応予定です。

**Q: スキルツリーが表示されない**

A: ツールバーのスキルツリーアイコン（🎮）をクリックしてください。見つからない場合は、marimoを最新版にアップデートしてください。
